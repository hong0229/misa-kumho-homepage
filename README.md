## 편집 가능한 소스

릴리스의 `misa-kumho-source.zip`에는 `dist/` 웹 소스와 사진, `desktop/Launcher.cs`, `desktop/build.ps1`, 아이콘, `preview.mjs`와 편집 안내를 포함합니다. Windows PowerShell에서 `desktop/build.ps1`을 실행하면 실행파일을 다시 만들 수 있습니다.

실행기는 Windows에 기본 제공되는 .NET Framework 4.5 이상을 사용하고, 내장 파일을 `%LOCALAPPDATA%\MisaKumhoHomepage`에 풀어 이 PC의 `127.0.0.1`에서만 제공합니다. 관리자 권한이나 자동 시작 등록은 사용하지 않습니다.

검증: 실행파일에 포함된 홈페이지 자원 60개의 HTTP 응답과 파일 해시 일치를 확인했습니다. 단지 수치·가격·개발계획은 제공된 2026년 11월 브리핑의 참고 자료입니다. 현재 등록 매물은 위 네이버 부동산 링크에서 확인할 수 있습니다.
